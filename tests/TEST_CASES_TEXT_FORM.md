# 成语接龙 - 测试用例文档（文本形式）

本文档根据现有 Playwright 测试文件提炼，用纯文本描述了所有测试用例的功能意图。由于 Ionic 迁移后 UI 选择器完全不同，这些用例将作为重写测试的参考依据。

---

## 1. 无尽模式 (endless-mode.spec.ts + endless-mode-extended.spec.ts)

### 1.1 基础功能
- **TC-ENDLESS-001**: 从主页点击"无尽模式"卡片后，页面应导航至游戏页面，标题显示"无尽模式"
- **TC-ENDLESS-002**: 游戏页面应显示电脑给出的第一个成语气泡
- **TC-ENDLESS-003**: 输入框应可见并可用，placeholder 提示输入成语
- **TC-ENDLESS-004**: 提交按钮应可见

### 1.2 成语提交
- **TC-ENDLESS-005**: 提交正确成语后，输入框应清空
- **TC-ENDLESS-006**: 提交正确成语后，用户消息气泡应显示提交的成语
- **TC-ENDLESS-007**: 提交正确成语后，AI 应自动回复一个新的成语
- **TC-ENDLESS-008**: 提交不存在的成语时，应显示错误气泡，错误原因显示"成语不存在"
- **TC-ENDLESS-009**: 提交重复成语时，应显示错误气泡，错误原因显示"成语已使用"
- **TC-ENDLESS-010**: 提交拼音不匹配的成语时，应显示错误气泡，错误原因显示"拼音不匹配"
- **TC-ENDLESS-011**: 提交错误成语后输入框应清空
- **TC-ENDLESS-012**: 错误消息不应显示耗时
- **TC-ENDLESS-013**: 提交错误后计时器不应重置

### 1.3 得分
- **TC-ENDLESS-014**: 提交正确成语后得分应增加
- **TC-ENDLESS-015**: 得分显示应实时更新
- **TC-ENDLESS-016**: 正确消息应在消息气泡中显示得分

### 1.4 放弃按钮
- **TC-ENDLESS-017**: 无尽模式应显示"放弃"按钮
- **TC-ENDLESS-018**: 点击"放弃"按钮后游戏应结束
- **TC-ENDLESS-019**: 放弃后消息列表中应出现"放弃"提示气泡
- **TC-ENDLESS-020**: 放弃后应显示游戏结束弹窗
- **TC-ENDLESS-021**: "放弃"按钮文字不应被截断（移动端）
- **TC-ENDLESS-022**: "放弃"按钮应显示为次要按钮样式

### 1.5 消息交互
- **TC-ENDLESS-023**: 点击用户消息气泡应打开成语详情弹窗
- **TC-ENDLESS-024**: 点击电脑消息气泡应打开成语详情弹窗
- **TC-ENDLESS-025**: 右键点击电脑消息气泡应打开候选成语弹窗
- **TC-ENDLESS-026**: 在移动端长按消息气泡应打开候选成语弹窗
- **TC-ENDLESS-027**: 短按消息气泡（移动端）应打开详情弹窗
- **TC-ENDLESS-028**: 打开详情弹窗时不应抢夺输入框焦点
- **TC-ENDLESS-029**: 关闭详情弹窗后输入框应保持焦点
- **TC-ENDLESS-030**: 关闭候选成语弹窗后输入框应保持焦点

## 2. 限时模式 (limited-time-mode.spec.ts)

### 2.1 配置页面
- **TC-LIMITED-001**: 点击"限时模式"卡片应导航到配置页面
- **TC-LIMITED-002**: 配置页面应显示游戏时长输入框
- **TC-LIMITED-003**: 配置页面应显示预设时长按钮（1分钟、2分钟、3分钟、5分钟）
- **TC-LIMITED-004**: 调整按钮(+/−)应能改变时长值
- **TC-LIMITED-005**: 点击"开始游戏"按钮应导航到游戏页面

### 2.2 游戏中的计时
- **TC-LIMITED-006**: 游戏页面应显示剩余的全局时间
- **TC-LIMITED-007**: 全局时间应逐秒递减
- **TC-LIMITED-008**: 全局时间剩余 <= 30秒时，显示应变为警告样式
- **TC-LIMITED-009**: 全局时间耗尽后游戏应结束
- **TC-LIMITED-010**: 游戏结束时如果未达配置时长，得分应准确反映

### 2.3 输入焦点
- **TC-LIMITED-011**: 进入游戏页面后输入框应自动获得焦点
- **TC-LIMITED-012**: 全局时间耗尽时不应自动聚焦输入框
- **TC-LIMITED-013**: 游戏结束弹窗关闭后不应尝试聚焦输入框

## 3. 多人模式 (multiplayer-mode.spec.ts)

### 4.1 玩家设置页面
- **TC-MULTI-001**: 点击"多人模式"卡片应导航到玩家设置页面
- **TC-MULTI-002**: 玩家设置页面应显示输入框和"添加玩家"按钮
- **TC-MULTI-003**: 可以添加玩家并显示在列表中
- **TC-MULTI-004**: 每个玩家应有独特的头像颜色
- **TC-MULTI-005**: 可以删除已添加的玩家
- **TC-MULTI-006**: 最少需要2名玩家才能开始
- **TC-MULTI-007**: 最多可添加8名玩家
- **TC-MULTI-008**: 玩家不足时点开始按钮应显示错误提示

### 4.2 游戏玩法
- **TC-MULTI-009**: 开始游戏后应显示记分板
- **TC-MULTI-010**: 当前回合玩家应有视觉标识
- **TC-MULTI-011**: 提交正确成语后应轮到下一位玩家
- **TC-MULTI-012**: 提交错误时该玩家应受到惩罚
- **TC-MULTI-013**: 第一个成语回合应显示"先手"提示
- **TC-MULTI-014**: 游戏结束弹窗应显示所有玩家的最终排名

## 5. 收藏夹 (favorites.spec.ts + long-press-detail-modal.spec.ts)

### 5.1 添加/取消收藏
- **TC-FAV-001**: 详情弹窗中应显示收藏按钮(星号图标)
- **TC-FAV-002**: 点击收藏按钮应添加收藏，图标变为实心星
- **TC-FAV-003**: 再次点击应取消收藏，图标变为空心星
- **TC-FAV-004**: 收藏状态应在 localStorage 中持久化

### 5.2 收藏夹页面
- **TC-FAV-005**: 侧边菜单点击"收藏夹"应导航到收藏夹页面
- **TC-FAV-006**: 收藏夹页面应按拼音首字母分组显示
- **TC-FAV-007**: 每个分组应可展开/折叠
- **TC-FAV-008**: 分组标题应显示该组成语数量
- **TC-FAV-009**: 点击成语应打开详情弹窗
- **TC-FAV-010**: 收藏夹页面应显示总计数

## 6. 成语词典 (idiom-library.spec.ts)

### 6.1 基础功能
- **TC-LIBRARY-001**: 侧边菜单点击"成语词典"应导航到词典页面
- **TC-LIBRARY-002**: 词典页面应显示所有成语列表（按字母排序）
- **TC-LIBRARY-003**: 搜索框应可用，输入可筛选成语
- **TC-LIBRARY-004**: 搜索应匹配成语、拼音、释义

### 6.2 搜索模式
- **TC-LIBRARY-005**: "开头匹配"模式应只搜索以关键词开头的条目
- **TC-LIBRARY-006**: "搜索释义"开关应控制是否搜索释义和出处
- **TC-LIBRARY-007**: 匹配的关键词应高亮显示

### 6.3 滚动加载
- **TC-LIBRARY-008**: 列表应支持滚动加载更多
- **TC-LIBRARY-009**: 点击成语条目应打开详情弹窗
- **TC-LIBRARY-010**: 详情弹窗中应显示该成语的搜索结果高亮

## 10. 数据导入导出 (import-export.spec.ts)

### 10.1 导出
- **TC-IMPORT-EXPORT-001**: 侧边菜单应有"导出数据"菜单项
- **TC-IMPORT-EXPORT-002**: 点击"导出数据"应下载 JSON 文件
- **TC-IMPORT-EXPORT-003**: 文件名格式应为 "chengyujielong_YYYYMMDD_HHMMSS.json"
- **TC-IMPORT-EXPORT-004**: 文件应包含 sessions、patches、favorites 三个字段

### 10.2 导入
- **TC-IMPORT-EXPORT-005**: 侧边菜单应有"导入数据"菜单项
- **TC-IMPORT-EXPORT-006**: 点击后应打开文件选择器
- **TC-IMPORT-EXPORT-007**: 选择有效 JSON 文件后应显示"导入成功"提示
- **TC-IMPORT-EXPORT-008**: 选择无效文件后应显示"导入失败"错误提示
- **TC-IMPORT-EXPORT-009**: 导入后数据应反映在 localStorage 和 UI 中

## 14. 辅助功能与细节

### 14.1 输入焦点
- **TC-FOCUS-001**: 输入框在页面加载后应自动获得焦点
- **TC-FOCUS-002**: 打开弹窗时不应抢夺输入框焦点
- **TC-FOCUS-003**: 关闭弹窗后输入框应保持焦点
- **TC-FOCUS-004**: 点击候选弹窗中的统计项不应抢夺焦点

### 14.2 错误耗时
- **TC-ERROR-001**: 错误消息不应显示耗时
- **TC-ERROR-002**: 提交错误后计时器不应重置
- **TC-ERROR-003**: 错误消息后的正确消息应显示正确耗时

### 14.3 提交后输入清空
- **TC-CLEAR-001**: 正确提交后输入框应清空
- **TC-CLEAR-002**: 错误提交后输入框应清空
- **TC-CLEAR-003**: 在所有游戏模式中提交后输入框都应清空
